# LESSONS — every production problem, and where it is now prevented

**The rule (Salah, 2026-09-24):** a problem found in any test, take or edit is never fixed only in the
kit or the clip. In the same sitting it is (1) written into every skill that could produce it again,
(2) made a gate wherever a script can detect it, and (3) logged here. A lesson with no gate says why.
Every mode reads this file before it starts; Mode 4's gates run the checks on every kit.

**The status column (added in the 2026-09-28 cleanup).** Rows are never deleted — a superseded row is the record of
something that was tried and failed, which is exactly what stops a later session trying it again. Only rows marked
**live** (or the live part of a **partly live** row) are rules; each skill's *Tested and ruled out* list names the rest.
